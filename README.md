# Полный проект «Сайт-резюме и визитная карточка с QR-кодом»

## Структура
- `index.html` — одностраничный сайт-резюме
- `style.css` — современный адаптивный дизайн
- `script.js` — небольшая интерактивность
- `assets/` — папка для фотографии и QR-кода

## Что нужно заменить
В `index.html` замените:
- Иван Иванов
- возраст
- город
- учебное заведение
- специальность и квалификацию
- навыки
- место практики
- проекты
- телефон
- e-mail
- GitHub
- блок «ФОТО» на реальную фотографию

## Публикация
Проект можно разместить на бесплатном статическом хостинге (например, GitHub Pages).
После публикации получите постоянную ссылку и создайте QR-код, ведущий на `index.html`.

## Визитная карточка
Макет рекомендуется делать отдельным файлом/страницей после того, как известна финальная ссылка сайта, потому что QR-код должен вести именно на опубликованную страницу.
